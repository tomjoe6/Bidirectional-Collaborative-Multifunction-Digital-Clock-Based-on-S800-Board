# 扩展功能：节日祝福 + 语音指令

## 一、节日开机祝福

### 实现逻辑

```
PC 连接板子 → 3s 后自动拉天气 → 5s 后再等 3s → 检测当天日期
  ├─ 命中节日 → 发送 *SET:MSG <greeting>，数码管显示 5s
  └─ 非节日 → 无操作
```

### 节日表

| 日期 | 祝福语（≤8字符） |
|:---|:---|
| 1月1日 | `HappyNew` |
| 2月14日 | `Love You` |
| 5月1日 | `51Happy ` |
| 6月1日 | `61Happy ` |
| 9月10日 | `Teachers` |
| 10月1-3日 | `NationDy` |
| 12月25日 | `MerryXma` |

### 代码

**文件：`pc_host/holiday.py`**

```python
from datetime import date

HOLIDAYS = {
    (1,  1):  "HappyNew",
    (2, 14):  "Love You",
    (5,  1):  "51Happy ",
    (6,  1):  "61Happy ",
    (9, 10):  "Teachers",
    (10, 1):  "NationDy",
    (12, 25): "MerryXma",
}

def get_greeting() -> str:
    today = date.today()
    return HOLIDAYS.get((today.month, today.day), "")
```

**调用点：`pc_host/ui_main_window.py`** 中的 `_on_worker_connected`

```python
from holiday import get_greeting
greeting = get_greeting()
if greeting:
    def _send_greeting():
        cmd = f"*SET:MSG {greeting}\r\n"
        if self._serial_worker and self._serial_worker.is_connected():
            self._serial_worker.send(cmd.encode("ascii"))
            self.log_panel.addEntry("TX", f"节日祝福: {greeting}")
    QTimer.singleShot(8000, _send_greeting)
```

### 原理

- 基于 PC 系统日期 `date.today()`，不依赖板子时钟
- 用 `QTimer.singleShot(8000)` 延迟 8 秒发送（等开机动画 + 天气走完）
- 非节日不发任何命令，完全透明

## 二、语音指令

### 架构

```
🎤 按钮（工具栏）
  ├─ 点击 → VoiceWorker(QThread).start()
  │   ├─ pyaudio 采集 PC 默认麦克风 → 音频字节流
  │   ├─ Vosk 离线引擎 (vosk-model-small-cn-0.22) → 中文字符串
  │   ├─ 正则匹配关键词 → 提取参数
  │   ├─ 持续循环：录音 → 识别 → 匹配
  │   └─ 匹配成功 → Qt 信号 → 调现有方法
  └─ 再点击 → VoiceWorker.stop()

完整流程：
  麦克风 → pyaudio 采集 → Vosk 离线语音→文字
  → "设八点三十分的闹钟"
  → 正则 r'设[定]?\s*(\S{1,3})点\s*(\S{0,3})\s*(?:(?:分|的))?\s*闹钟'
  → 小时=8, 分钟=30
  → *_parse_num("八")=8, _parse_num("三十")=30*
  → emit alarm_cmd(8, 30)
  → _on_voice_alarm → *SET:ALARM HOUR 08 MIN 30 SEC 00
```

### 支持的两条指令
>目前只做了上位机处点击开始录音才能识别
| 语音 | 触发动作 | 发送命令 |
|:---|:---|:---|
| 「设X点Y分的闹钟」 | 设置闹钟 | `*SET:ALARM HOUR X MIN Y SEC 00` |
| 「设X点的闹钟」 | 设置闹钟（分钟=0） | `*SET:ALARM HOUR X MIN 00 SEC 00` |
| 「今天天气怎么样」 | 拉取天气 | 调用 `_on_weather_fetch()` |

### 容错

- 数字支持：`8` / `八` / `二十三` / `廿`
- 「设」「设定」均可
- 「分」可省略（「8点的闹钟」→ 08:00）
- 「的」可省略
- 小时 0-23，分钟 0-59，超范围忽略

### 代码

**文件：`pc_host/voice_thread.py`** 核心匹配逻辑

```python
class VoiceWorker(QThread):
    recognized = pyqtSignal(str)      # 原始识别文本
    alarm_cmd = pyqtSignal(int, int)  # 闹钟 时,分
    weather_cmd = pyqtSignal()        # 天气

    _ALARM_RE = re.compile(
        r'设[定]?\s*(\S{1,3})点\s*(\S{0,3})\s*(?:(?:分|的))?\s*闹钟'
    )
    _WEATHER_RE = re.compile(r'(今天)?天气(怎么样)?|获取天气')

    def _dispatch(self, text):
        m = self._ALARM_RE.search(text)
        if m:
            h = self._parse_num(m.group(1))
            m_val = self._parse_num(m.group(2)) if m.group(2).strip() else 0
            if h is not None and 0 <= h <= 23 and 0 <= m_val <= 59:
                self.alarm_cmd.emit(h, m_val)
                return
        if self._WEATHER_RE.search(text):
            self.weather_cmd.emit()
```

**文件：`pc_host/ui_main_window.py`** 连接信号

```python
def _toggle_voice(self):
    if self._voice_worker and self._voice_worker.isRunning():
        self._voice_worker.stop()
        self._voice_worker = None
        self.btn_mic.setText("🎤")
        return

    self._voice_worker = VoiceWorker()
    self._voice_worker.recognized.connect(
        lambda t: self.log_panel.addEntry("EVT", f"语音: {t}")
    )
    self._voice_worker.alarm_cmd.connect(self._on_voice_alarm)
    self._voice_worker.weather_cmd.connect(self._on_weather_fetch)
    self._voice_worker.start()
    self.btn_mic.setText("🔴")
```

### 依赖

```bash
pip install speechrecognition pyaudio vosk
```

- `speechrecognition`：封装各类 ASR 引擎
- `pyaudio`：PC 麦克风采集
- `vosk`：离线语音识别引擎，**免费、无需联网、无需注册**

还需下载 Vosk 中文模型（42MB）：
https://alphacephei.com/vosk/models/vosk-model-small-cn-0.22.zip  
解压到 `pc_host/vosk-model-small-cn-0.22/`（am/conf/graph/ivector 四个目录直接在下面）

### 板端影响

**零改动**。所有指令最终转换为 `*SET:ALARM` / `*SET:MSG` 等已有串口命令，板端协议栈无需任何修改。
